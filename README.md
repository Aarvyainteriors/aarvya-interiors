# Aarvya Interiors Website

A responsive, one-page interior design website built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — website content and sections
- `style.css` — responsive layout, colors, typography and animations/hover effects
- `script.js` — WhatsApp, Instagram and mobile navigation settings
- `assets/aarvya-logo.jpeg` — your supplied Aarvya Interiors and Design logo

## Before publishing
1. Open `script.js`.
2. Your WhatsApp number and Instagram profile are already configured in `script.js`. Your supplied logo is included in `assets/aarvya-logo.jpeg` and displayed in the header and footer.
3. Your Bengaluru business address is already added to the Contact section.
4. In `index.html`, replace the sample inspiration photos with photos of your own completed projects. The current photos are loaded from Unsplash and require an internet connection.
5. Update the About and Services copy to match the exact services you offer.

## Publish with GitHub Pages
1. Create a GitHub repository, for example `aarvya-interiors`.
2. Upload `index.html`, `style.css`, `script.js` and this `README.md` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then click **Save**.
6. After GitHub finishes publishing, your site will be available at the Pages URL shown in Settings → Pages.

You can use that URL in your Instagram bio.

## Notes
- No build step or framework is required.
- Google Fonts and Unsplash images are external resources.
- The gallery is starter inspiration, not a claim that these are Aarvya Interiors' completed projects.
